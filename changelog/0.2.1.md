# Paster Dream Reborn v0.2.1 (Forge 1.20.1)

版本号：`0.2.1-forge-1.20.1`

## ✨ 更新概览

本次更新新增萦风雷矛、白砂岩 / 染梦砂岩建材、眠椰块与风泊树苗等内容，完善料理溢出、受保护效果、SAN 变化率显示等机制，为染梦营地提供全新战利品，并对武器数值与配方进行了平衡调整，同时修复了大量问题。

### 新增

**武器与物品**
- 添加毕业级长柄武器「萦风雷矛」：左键近战附带雷伤，普通右键蓄力突进（激流式前冲），Shift+右键蓄力投掷虚影，命中后触发连锁闪电并自动飞回；附带「雷随疾风」被动（移速越高伤害越高，掉落物被风卷至身边），突进与投掷消耗融梦能量
- 添加炙炎金材质资源与旧版材质包
- 巧克力重命名为「存储元件」/「storage cell」时切换为存储元件纹理
- 将已弃用的寻梦者笔记拆分至新的创造模式物品栏

**方块与建材**
- 添加白砂岩建材系列：白砂岩、切制 / 雕纹 / 平滑白砂岩，及对应的楼梯、台阶、墙
- 添加染梦砂岩建材系列：染梦砂岩、切制 / 雕纹 / 平滑染梦砂岩，及对应的楼梯、台阶、墙
- 添加眠椰块（形态支持 16 向旋转、贴墙形态支持四向），树冠枝条上随机悬挂眠椰块，含专用方块实体渲染
- 添加风泊树苗及盆栽变体；风泊树叶改为普通可腐烂树叶并掉落树苗，树冠可装饰无花果藤与下垂树叶
- 阴影书架现在可提供附魔之力（附魔台两格内生效），并将阴影蘑菇加入蘑菇标签
> **注意**：眠椰并没有加入世界生成，无法在生存模式获取  

**机制与效果**
- 新增料理溢出机制：满饱食度时仍可进食，溢出的营养转化为生命值 / 黄心，上限随料理等级提升
- 实现受保护效果防移除机制，回避效果纳入其中，无法被常规方式清除
- 添加精神值变化率同步与 SAN 变化箭头显示，并可在客户端配置中开关
- 为暗影生物添加远离营火的 AI 行为
- 无名实体对话进行中时，其它玩家交互将提示其忙碌状态
- 工艺类方块在收到外部红石信号上升沿时尝试合成
- 配置新增：染梦世界跃迁石开关 `dyedreamWorldLeapstoneEnabled`（默认关闭，跃迁石配方受其控制）、JEI 流体显示开关 `showFluidsInJei`

**世界与维度**
- 实现灯影之下维度的降雨功能（黑色降雨）
- KubeJS 新增梦境维度插件：允许自定义维度是否为梦境维度，并支持删除 / 判断梦境维度

**技能与工具**
- 为折翼天使雕像添加瞬身装填弩功能：使用瞬身后即时装填主手弩
- 添加调试工具（创造模式「调试栏」）：可在游戏内编辑方块、实体、物品的 NBT 与物品栏 / 流体 / 能量存储，支持翻页与充放电

**战利品与兼容**
- 为染梦营地定义全新战利品表，新增 3 条 tooltip，并添加旅人标题（Traveler's Titles）兼容
- 罪恶预言卡优化对灾厄村民的判断：能对所有灾厄村民类实体造成伤害以兼容其它模组，秒杀对象新增灾厄溢出的村民幽魂

### 平衡调整
- 大地之刃支持 Shift+右键开关剑气状态
- 白厄花胸针与堕落者之印改为实现 ISanModifier 接口
- 疾风连击附魔区分剑与斧的不同加成比例

### 修复
- 修复精铸工坊合成时的 NBT 空指针异常
- 修复灯影之下维度噪声设置
- 修复阴影笔记废墟与逐梦列车中的错误笔记
- 修复储物袋格子错位及两个储物袋缺少 ItemHandler 的问题
- 修复武器战技导致的实体战利品抢夺附魔失效的问题
- 修复研钵流体容器功能兼容性（JEI 配方丢失与类型转换异常）
- 修复友善怨魂实体的目标选择器配置
- 修复塞西莉亚的加护的修复逻辑（非创造模式消耗与客户端 / 服务端同步）
- 修复传送门屏幕叠加层材质显示与切换闪烁问题
- 修复生物生成事件的生物群系检查逻辑，修复粉红羊的生成
- 修正灵魂石工具提示颜色显示
- 修复 sword_wave 音效音量问题
- 将模组中的沙子加入沙子标签
- 更新生物词条与成就关联
- 修复编辑 NBT 时读取到缓存的问题
