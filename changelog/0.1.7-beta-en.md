# Paster Dream Reborn v0.1.7-beta (Forge 1.20.1)

Version: `0.1.7-forge-1.20.1-beta`

This update completes the Lamp Shadow world storyline and fully overhauls the Wind Knight system, along with many fixes.

## Added
- Ironwind series blocks, tools and Cyclone Alloy equipment set with wind-whirl passive effects
- Wind Pavilion Desk, Clover Potted Plant and other new blocks; bone meal support for Verdant Moss Stone and Shadow Fungus Stone
- Shadow Breath curio, new music discs, Wind Walker Jelly, custom fluid rendering and potion effects for Spirit Medicine Bottles
- Painting item support, mod rarity system with KubeJS integration
- New Shadow Dungeon structures (portal frame + full interior), updated Journey of the Wind structures
- Clover world generation feature
- Wind Knight overhaul: lightning strike attacks, configurable skill/passive invincibility, immunity to negative status effects
- Thundercloud entities auto-track players; high-voltage cloud state persistence
- Wind Knight altar activation with Thunderbolt Potion Bottles (right-click)
- Completed Lamp Shadow storyline: new quest lines and Dream Note books (grant advancements on open)
- Arena challenge clear-out logic
- New loot tables: Journey of the Wind chests, Melt Dream crystal chests; Clover Charm added to multiple tables

## Fixed
- Status effects lost when teleporting across dimensions; cloud effect display/removal issues
- Melt Dream tool and crystal equipment smithing recipes
- Dream Reservoir network packet and Mortar recipe fluid output serialization issues
- Mob spawn configs with new spawn budget limits; Christmas Tree Island structure
- Ghost Mask no longer duplicates split projectiles (now has configurable built-in cooldown)

## Changed / Refactored
- Wind Knight animation system and attack logic rebuilt; BOSS damage-cap and boss bar layout systems reworked
- Dialogue system reworked as a state machine
- Angel Wings / Forgotten Wings converted from armor to back accessories
- Melt Dream equipment moved from crafting table to smithing table recipes
- Thundercloud entities refactored into an abstract base class; client code structure reorganized

## Balance
- Adjusted mob spawn budget, empty loot box weights, and Melt Dream equipment drop tables
- Adjusted Aaroncos left/right hand entity HP and damage resistance levels
