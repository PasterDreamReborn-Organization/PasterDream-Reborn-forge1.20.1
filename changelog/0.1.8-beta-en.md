# Paster Dream Reborn v0.1.8 (Forge 1.20.1)

Version: `0.1.8-forge-1.20.1-beta`

This update expands items, recipes and structures, completes the Journey of the Wind advancement and storyline system, and fixes many lingering issues.

## Added
- Shadow Jelly item, Broken-Winged Angel Statue and Wind Sprite curios; Dream Train ticket functionality with richer train loot
- Magnifying glass fire resistance; NBT-based attack_boost and luck_boost attributes
- Melt Dream Cauldron recipes for many potions, compressed Dyedream Ice recipe, Strawberry Sweetheart recipe, and Spell Factory fluid output
- Wind Chime Cage structure and new painting variants
- Friendly Wraith settle mode and taming (with a new advancement)
- Journey of the Wind advancement series (dimension progress, flight challenges, entrance guidance) and firefly catching system
- Melt Dream Crystal Chest energy reward; KubeJS support for skill cooldown; JEI fluid container binding display

## Fixed
- Recipe matching and processing logic (including Mortar recipes) and fluid check logic
- Forge fluid milk and water bottle fluid binding issues
- Shadow Blade skill damage source and Wind Alloy Sword skill trigger issues
- Typo fixes in tooltips and Cecilia item names; magnifying glass description format
- Shadow Dungeon flora drop issue and chest loot table adjustments

## Changed / Refactored
- Dream Note book registration simplified; recipe matcher data structure optimized
- Curio creative tab order reorganized; Terra Sword Aura entity collision and particles improved
- Lamp Shadow world advancement system reworked; Blade of Extreme Frost cooldown optimized
- Soul Gem attribute modifier implementation rebuilt; Shadow Blade SAN ratio update logic optimized

## Renamed
- Lost Wind Knight Ruins renamed to Windbreaker Knight Altar; Christmas Tree structure renamed to Christmas Tree Island
- Related resource files renamed accordingly
