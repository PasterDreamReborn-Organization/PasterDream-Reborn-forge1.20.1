# 更新日志

## v1.0.0（Forge 1.20.1）

版本号：`1.0.0-forge-1.20.1`

### 新增

- 添加创造模式下《旧梦归引》自动解锁全部词条的行为，处于创造模式时忽略剧情进度锁，并添加配置项「创造模式下解锁全部帕秋莉词条」，默认开启

### 调整

- 更新《旧梦归引》的「寻梦者笔记」条目，补充笔记存在碎片形态、可从遗迹与敌人身上搜刮碎片的说明
- 扩写《旧梦归引》的「料理」条目，补充饱腹时继续进食与溢出饱食度转化为生命、黄心的规则，并注明黄心上限随料理等级提高
- 修正《旧梦归引》中振奋、不振与恍惚条目的冷却缩减表述，将「技能冷却时间」改为「战技冷却缩减」
- 统一物品描述、进度文本与笔记文本中的省略号和括号写法，中文使用「……」与全角括号，英文使用「...」与半角括号

### 修复

- 修复重进存档后本模组饰品被判定为重复并从饰品栏掉回物品栏的问题
- 修复部分染梦教堂结构的名称不显示的问题
- 修正「丛林之力」与「刀下亡魂」进度描述中的错别字，将「草雍」改为「草薙」

### 技术

- 添加语言文件校验工具，检查编码、行尾、省略号、括号与重复键，并接入 `check` 任务链与 CI
- 修正草薙毒刺伤害相关注释与设计文档中错误标注的附魔加成说明
