# Paster Dream Reborn v0.2.0-beta (Forge 1.20.1)

版本号：`0.2.0-forge-1.20.1-beta`

## ✨ 更新概览

本次更新主题为**荒野更新 · 染梦世界部分**，重写了染梦世界维度的群系体系，并大规模扩充了地物、矿石、传送门、结构与剧情内容。

### 新增

**生物群系**
- 重写染梦世界维度群系体系：基于温度 / 湿度 / 大陆性 / 侵蚀度 / 怪异度 / 深度六维气候参数，构建 16 个多噪声群系，并重写地表规则、群系标签与地物注入方式
- 新增染梦花海、染梦森林、染梦樱雪森林、染梦沙滩、染梦河流、染梦冻河、染梦冷海、染梦雪山（冰尖峰）、染梦洞穴、染梦繁茂洞穴、染梦滴水洞穴
- 调整染梦平原、染梦雪原、染梦菇山、染梦海洋、染梦冻洋
- 为染梦世界全部群系补全中英文本地化

**地物与植被**
- 将染梦世界地物生成改为按生物群系标签分组注入
- 为染梦树下添加流明光球
- 添加染梦森林的萤火虫巢生成
- 添加粉顶菇垂帘（染梦繁茂洞穴洞顶悬挂结构）
- 添加染梦世界河流群系的河流粘土生成（镜像原版 disk_clay）
- 添加染梦花海的密集梦染茶花、浮空流明光球，以及按坐标噪声错落的混合花卉
- 降低茎草与高茎草的生成频率

**矿石与地下**
- 添加染梦世界方解石矿物系统（煤、铁、铜、金、红石、青金石、钻石、绿宝石），含配置特征、放置特征、战利品表、模型、材质与挖掘标签

**树木与方块**
- 添加眠椰树，以及眠椰原木、眠椰木、去皮眠椰原木、去皮眠椰木、眠椰树叶、眠椰木板、眠椰树苗、盆栽眠椰树苗。眠椰树未正式加入世界生成
- 添加蔚蓝海沙方块
- 将染梦草方块改为继承 SnowyDirtBlock，支持积雪状态

**饮品与流体**
- 添加眠椰、眠椰苏打水、海盐眠椰饮与马天尼杯等物品，以及眠椰汁、眠椰苏打水、海盐眠椰饮流体，配套合成与研钵配方

**传送门与染梦侵染**
- 添加染梦世界传送门系统：染梦世界跃迁石、传送门方块、染梦粉尘、框架识别与激活、跨维度传送、战利品表与方块状态
- 添加染梦侵染功能：传送门与染梦裂隙随机刻侵染、侵染方块标签与转换规则、JEI 配方展示
- 添加梦境裂缝方块首次接触消息的第四行

**结构与世界生成**
- 重构染梦世界固定坐标 (2002, 1128) 处的世界树放置逻辑：新增 FixedChunkStructurePlacement 固定坐标结构放置类型、ModStructurePlacementTypes 注册表与结构集排除区配置
- 更新逐梦列车结构
- 添加染梦世界水生生物生成配置（鳕鱼、鲑鱼、河豚、热带鱼、鱿鱼）
- 将客栈与营地结构的生成条件由平原改为全部陆地群系

**进度与剧情**
- 添加染梦裂隙剧情书，重构染梦裂隙进度触发与笔记发放逻辑，移除所有图片笔记的发放
- 新增梦境笔记书籍：美梦世界研究、染梦世界跃迁石、梦境世界的本质、风铃笼
- 添加染梦世界跃迁石帕秋莉宝典条目

**兼容与渲染**
- 添加光影（Oculus/Iris）兼容层与植物 / 树叶方块动效注入，复用原版草与树叶的 shader ID 获得光影飘动
- 添加对双高度植物的光影动效支持

**维度功能**
- 修复 1.20.1 自定义维度的睡眠与天气指令功能：玩家可在染梦世界和风之旅途入睡，并正常跳过夜晚与设置天气
- 实现跨维度传送效果补发机制，修复传送后状态效果丢失问题

### 修复
- 修复染梦冻洋地表生成规则
- 修正染梦晶洞外层材质（黑石改为闪长岩）
- 修正染梦维度群系温度参数配置，提高染梦雪原的生成概率
- 修复生物群系粒子效果配置，统一改用原版樱花叶粒子
- 修复作物方块的形状偏移问题
- 修复染梦裂隙笔记重复发放问题
- 修复教堂宝箱掉落融梦水晶战利品的问题
- 修复寻梦者笔记所在结构的编号
- 修复联机与光影环境下的渲染状态残留问题
- 修正裂隙首次接触消息中的视角代词
- 修正含 NBT 但不含 AttackBoost / LuckBoost 物品的空工具提示

### 重构
- 重构染梦维度地物生成系统，由简单注入改为基于生物群系标签的分组注入
- 重构生物群系植被生成配置，重新组织海泡菜与通用植被标签
- 优化生物群系地物生成配置（花海混合花卉按噪声分布、染梦世界结冰、统一 FREEZE_TOP_LAYER 等）
- 更新染梦世界维度群系生成参数与地表规则
