# Paster Dream Reborn v0.1.8 (Forge 1.20.1)

版本号：`0.1.8-forge-1.20.1-beta`

## ✨ 更新概览

本次更新扩充了物品、配方与结构内容，完善了风之旅途进度与剧情体系，并修复了大量遗留问题。

### 新增

**物品**
- 添加暗影果冻物品及相关功能
- 添加折翼天使雕像饰品
- 添加风精灵饰品
- 添加逐梦列车车票功能，并让列车结构中的战利品更加丰富
- 添加放大镜的火焰抗性功能
- 添加寻梦者笔记书到原版雕纹书架标签
- 添加通过 NBT 实现的 attack_boost 和 luck_boost 属性加成

**配方**
- 为融梦釜添加力量、神龟、缓降、抗火、生命提升、跳跃提升、水下呼吸、再生、瞬间治疗、速度和幸运药水的相关配方
- 添加染梦浮冰压缩配方
- 添加草莓甜心合成配方
- 添加法术工厂的流体输出及其配方相关内容

**结构**
- 添加风铃笼结构并优化生成配置
- 添加新的画作变体

**实体**
- 添加友善怨魂驻留模式和驯服功能，并新增驯服友善怨魂的进度任务

**进度与剧情**
- 添加风之旅途系列进度（含维度进度、飞行挑战和进入引导进度）
- 添加萤火虫捕捉功能和相关进度系统
- 添加风之旅途相关帕秋莉宝典内容

**功能**
- 添加融梦水晶箱开启时的能量奖励功能
- 添加技能冷却系统的 KubeJS 支持
- 添加 JEI 流体容器绑定关系显示
- 添加药水的 IFluidHandler 相关内容
- 添加新的材质资源到美术资产清单

### 修复
- 修复配方匹配与处理逻辑（含研钵配方问题）
- 修复配方匹配中的流体检查逻辑
- 修复未启用 Forge 流体牛奶的问题
- 修复水瓶的流体绑定问题
- 修复影刃技能伤害来源问题
- 修复风合金剑技能触发异常
- 修正魔法石工具提示中的错别字
- 修正塞西莉亚相关物品名称拼写
- 修复放大镜的文案格式错误
- 修改魔法使的记录-其一剧情书的位置
- 移除结构名称中的编号后缀
- 修复暗影地牢中花草掉落物的问题
- 调整宝箱战利品表配置

### 重构
- 简化梦境笔记书籍内容注册
- 优化配方匹配器的数据结构和类型检查
- 重新整理饰品在创造模式物品栏中的顺序
- 优化泰拉剑气实体碰撞检测与粒子效果系统
- 重构灯影世界进度系统
- 优化极锋染梦合金剑冷却机制
- 重构灵魂宝石属性修改器实现
