# Paster Dream Reborn v0.2.0-beta (Forge 1.20.1)

Version: `0.2.0-forge-1.20.1-beta`

Themed **Wilderness Update · Dyedream World**, this update rewrites the Dyedream World biome system and greatly expands its features, ores, portals, structures and storyline.

## Added

**Biomes**
- Rewrote the Dyedream World biome system: 16 multi-noise biomes built from six climate parameters (temperature / humidity / continentalness / erosion / weirdness / depth), with rewritten surface rules, biome tags and feature injection
- Added Dyedream Flower Field, Dyedream Forest, Dyedream Cherry Grove, Dyedream Beach, Dyedream River, Dyedream Frozen River, Dyedream Cold Ocean, Dyedream Snowy Peaks and the Dyedream Caves / Lush Caves / Dripstone Caves
- Adjusted Dyedream Plains, Dyedream Snowy Plains, Dyedream Mushroom Mountains, Dyedream Ocean and Dyedream Frozen Ocean
- Completed Chinese and English localization for every Dyedream World biome

**Features & Vegetation**
- Dyedream World feature generation now injects by biome tag groups
- Added Light Balls beneath Dyedream trees
- Added Firefly Nest generation to the Dyedream Forest
- Added hanging Pink Mushroom veils (ceiling structures in the Dyedream Lush Caves)
- Added river clay generation to the Dyedream river biomes (mirrors vanilla disk_clay)
- Added dense Dyedream Corollas, floating Light Balls and coordinate-noise-scattered mixed flowers to the Dyedream Flower Field
- Reduced the generation frequency of short and tall grass

**Ores & Underground**
- Added the Dyedream World calcite ore system (coal, iron, copper, gold, redstone, lapis lazuli, diamond, emerald) with configured features, placed features, loot tables, models, textures and mining tags

**Trees & Blocks**
- Added the Slumber Palm tree, plus Slumber Palm Log, Wood, Stripped Log, Stripped Wood, Leaves, Planks, Sapling and Potted Sapling (the tree is not yet part of world generation)
- Added the Azure Sea Sand block
- Dyedream Grass Block now extends SnowyDirtBlock and supports a snowy state

**Drinks & Fluids**
- Added Slumber Palm, Slumber Palm Club Soda, Sea Salt Slumber Palm Beverage and Martini Glass items, plus Slumber Palm Juice, Slumber Palm Club Soda and Sea Salt Slumber Palm Beverage fluids, with matching crafting and Mortar recipes

**Portals & Dyedream Contamination**
- Added the Dyedream World portal system: Dyedream World Leapstone, portal block, Dyedream Dust, frame detection and activation, cross-dimension teleporting, loot tables and block states
- Added Dyedream Contamination: random-tick contamination from portals and Dyedream Cracks, contaminated block tags and conversion rules, and JEI recipe display
- Added the fourth line to the Dream Crack block's first-contact message

**Structures & World Generation**
- Reworked the Worldtree placement at the fixed coordinate (2002, 1128) in the Dyedream World: added the FixedChunkStructurePlacement type, the ModStructurePlacementTypes registry and structure set exclusion zones
- Updated the Dream Train structure
- Added aquatic mob spawn configs to the Dyedream World (cod, salmon, pufferfish, tropical fish, squid)
- Changed the Inn and Camp structures to generate in all land biomes instead of only plains

**Advancements & Story**
- Added the Dyedream Crack story book, reworked the Dyedream Crack advancement trigger and note distribution, and removed all picture-note distribution
- Added Dream Notes books: Dyedream World Research, The Dyedream World Leapstone, The Nature of the Dream World and Windbell Cage
- Added a Patchouli guide entry for the Dyedream World Leapstone

**Compatibility & Rendering**
- Added a shader (Oculus/Iris) compatibility layer and plant / leaf block animation injection, reusing vanilla grass and leaf shader IDs for shader-driven swaying
- Added shader animation support for double-height plants

**Dimension Features**
- Fixed sleeping and weather commands in custom 1.20.1 dimensions: players can now sleep in the Dyedream World and Wind Journey, correctly skipping the night and setting weather
- Implemented teleport effect re-application, fixing status effects lost after teleporting

## Fixed
- Dyedream Frozen Ocean surface generation rules
- Dyedream geode outer material (blackstone changed to diorite)
- Dyedream biome temperature parameters, raising the Dyedream Snowy Plains generation chance
- Biome particle configs unified to vanilla cherry leaf particles
- Crop block shape offset
- Duplicate Dyedream Crack note distribution
- Church chests dropping Melt Dream Crystal loot
- Structure numbering where the Dreamseeker Notes are found
- Rendering state residue in multiplayer and shader environments
- Viewpoint pronoun in the Crack's first-contact message
- Empty tooltips for items containing NBT but no AttackBoost / LuckBoost

## Changed / Refactored
- Dyedream feature generation reworked from simple injection to biome-tag-grouped injection
- Biome vegetation configs reorganized (seagrass and general vegetation tags)
- Biome feature generation optimized (noise-distributed mixed flowers in the Flower Field, Dyedream freezing, unified FREEZE_TOP_LAYER, etc.)
- Updated Dyedream World biome generation parameters and surface rules
