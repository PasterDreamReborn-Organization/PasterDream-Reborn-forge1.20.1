# Paster Dream Reborn v0.2.1-fix1 (Forge 1.20.1)

Version: `0.2.1-forge-1.20.1-fix1`

## ✨ Overview

This is a fix release for v0.2.1. It adds a built-in "Legacy Textures" resource pack and a JEI ingredient-display config option, adds tag compatibility for salt items and the Light Ball, and fixes the drink-item container return and the White Sword melee damage check.

### Added

**Features & Compatibility**
- Added the built-in "Legacy Textures" resource pack: enable it on the resource-pack screen to restore redrawn block and item textures to the original mod's look
- Added the `forge:salt` tag to salt items and switched the related recipes to use the tag, improving cross-mod item compatibility
- Added the Light Ball to the vanilla `completes_find_tree_tutorial` tree-structure tag
- Added a JEI client config option `showPotionElixirBottlesInJei`: controls whether potion-filled elixir bottles appear in JEI's ingredient list (default `false`; only the potion variants are hidden, empty elixir bottles are kept and still display correctly in recipes; requires a game restart)

### Fixed
- Fixed drink items not returning their container: added `craftRemainder` to the Elixir Bottle of Melt Dream and the Elixir Bottle of Rage Elixir, and drink items now check the fluid-container registry first
- Fixed the White Sword melee damage check: added a `directEntity` validation to prevent ranged damage from being misjudged as melee (and triggering the passive) when a White Sword is in the main hand and a ranged weapon in the off hand

### Docs & Standards
- Updated the programming standards document: added best practices for `LivingHurtEvent` melee detection, container-return requirements for drink items, and how to package built-in resource packs
