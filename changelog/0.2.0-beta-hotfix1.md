# Paster Dream Reborn v0.2.0-beta-hotfix1 (Forge 1.20.1)

版本号：`0.2.0-forge-1.20.1-beta-hotfix1`

## ✨ 更新概览

本次为 v0.2.0-beta 的热修复更新，补充了两个影世界挑战进度、逐梦列车车票维度白名单配置与衍梦肥泥配方，并更新了内容规范条款。

### 新增

**进度与剧情**
- 添加挑战进度「是……我杀了我？！」，用纷争预言卡标记悲泣尖啸怨魂即可达成
- 添加挑战进度「物归原主……？」，合成失落剑冢即可达成

**配方**
- 添加衍梦肥泥研钵配方：粉色史莱姆球 + 骨块可产出 9 个衍梦肥泥，研钵在合成过程中不被消耗

**功能**
- 添加逐梦列车车票维度白名单配置项 `trainTicketDimensionWhitelist`，默认包含原版三维度与模组的染梦世界、灯影之下、风之旅途
- 不在白名单中的维度使用车票时会提示「逐梦列车并没有在这里设立站点，无法停靠」
- 维度白名单采用缓存机制，提升验证性能并支持配置热重载

### 文档
- 更新内容规范条款：将「附属模组规范」修改为「内容规范」，适用范围扩展至以本模组为题材或载体发布的一切内容，并统一中英文条款表述
