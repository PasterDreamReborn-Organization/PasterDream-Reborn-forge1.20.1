# 重构说明目录

本目录存放**大型重构**的说明文档（架构级调整、跨多文件的机制重写、行为合并/统一等），与按版本发布的 `changelog/*.md` 区分开：版本 changelog 面向玩家/发布，本目录面向开发者，记录**为什么这么改、改了什么、有什么行为变化、以后怎么继续**。

## 命名

`YYYY-MM-DD-<主题>.md`，例如 `2026-11-12-tool-series-shared-behavior.md`。

同一主题后续追加改动时，优先在原文补充「后续变更」章节，而不是新开一份。

## 每份文档建议包含

1. 范围与日期、验证方式（`compileJava` / `runData` / `runClient`）
2. 背景与问题（旧实现为什么不行）
3. 方案演进与被否掉的方案（避免以后重复踩坑）
4. 最终结构与关键文件
5. 行为变更清单（玩家可感知的、存档/数据兼容相关的）
6. 新增/删除/修改文件
7. 配套文档与语言键变化
8. 增量指南（以后如何沿用该结构）
