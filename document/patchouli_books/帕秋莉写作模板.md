# 帕秋莉（Patchouli）宝典写作模板

> 本模板整合 Patchouli 官方文档（vazkiimods.github.io/Patchouli）与本项目（PasterDream Reborn）的实际约定，供新增 / 修改 `旧梦归引.md` 及其生成的 JSON 时参考。

---

## 一、总体结构

帕秋莉宝典由三部分组成：

```
data/pasterdream/patchouli_books/seniors_dream/book.json            # 书籍定义（数据侧）
assets/pasterdream/patchouli_books/seniors_dream/<lang>/categories/  # 分类
assets/pasterdream/patchouli_books/seniors_dream/<lang>/entries/     # 词条
assets/pasterdream/patchouli_books/seniors_dream/<lang>/templates/   # 可复用模板（本项目暂未使用）
```

- 命名空间：`pasterdream`
- 书籍 ID：`seniors_dream`（书名「旧梦归引」）
- 语言：`zh_cn`、`en_us` 各一份。**注意**：本项目目前 `en_us` 只镜像 JSON 文件结构，语言文本只维护在 `zh_cn`。

本项目的工作流是：**以 `document/patchouli_books/旧梦归引.md` 为源文件**，手动把内容同步成上面的 JSON + 语言键。

---

## 二、`.md` 源文件格式约定

`旧梦归引.md` 是内容源文件，格式约定如下：

| 写法 | 含义 | 映射到 JSON |
|------|------|-------------|
| `# 标题` | 一级分类（category） | `categories/<id>.json` |
| `# 父类-子类` | 子分类（嵌套，用 `parent`） | `categories/<父类>/<子类>.json` |
| `## 标题` | 词条（entry） | `entries/<分类路径>/<词条id>.json` |
| `[icon=xxx]` | 图标物品 | entry 的 `icon` 字段 |
| `[xxx物品展示]` / `[xxx方块展示]` | 物品/方块 spotlight 页 | `patchouli:spotlight` 页 |
| `[xxx的工作台配方]` | 合成配方页 | `patchouli:crafting` 页 |
| `[xxx.png]` / `[xxx]` | 图片页 | `patchouli:image` 页 |
| `(分页)` | 换页 | 拆分到下一页 |
| `——xxx` | 引言 / 风味文字 | 独立页，或页尾用 `$(br2)` 拼接 |

**层级规则**：一个 `#` 是一个分类；子分类的标题写 `父级-子级`，Patchouli 通过 `parent` 字段实现嵌套。`##` 是当前分类（或子分类）下的词条。

**分页判断**：`.md` 里部分 `(分页)` 标记可能缺失，同步时需自行按字数判断是否该拆页——正文明显超过一页能容纳的字数时，应主动拆成多个 `page<N>`（一般是正文主体一页、`——` 引言单独一页）。

示例：

```markdown
# 机制介绍
[icon=debug_sword]
本篇介绍模组中的核心机制。

## 融梦能量
[icon=dyedream_dust]
在屏幕的左下角，有一个能量条一般的图标，即为融梦能量。
(分页)
融梦能量的获取途径：
每开启一个融梦水晶箱可以获得2点融梦能量。
```

## 三、`book.json`（书籍定义）

本项目实际使用（`data/pasterdream/patchouli_books/seniors_dream/book.json`）：

```json
{
  "name": "pasterdream.seniors_dream",
  "landing_text": "pasterdream.seniors_dream.landing_text",
  "version": "1",
  "i18n": true,
  "use_resource_pack": true,
  "creative_tab": "pasterdream:pasterdream_dream_notes_tab",
  "book_texture": "patchouli:textures/gui/book_purple.png",
  "model": "pasterdream:seniors_dream_book",
  "custom_book_item": "pasterdream:seniors_dream_book"
}
```

常用字段（官方）：

| 字段 | 说明 |
|------|------|
| `name` / `landing_text` | 书名 / 开篇文字（翻译键） |
| `book_texture` | 书皮纹理，内置可选 `book_blue/brown/cyan/gray/green/purple/red.png` |
| `model` / `custom_book_item` | 书本物品模型 / 自定义书本物品 |
| `creative_tab` | 物品所在创造物品栏 |
| `i18n` | 是否走语言文件（本项目 `true`） |
| `use_resource_pack` | 1.20 起模组书必须设为 `true` |
| `version` / `subtitle` | 版本号 / 副标题 |
| `show_progress` | 是否显示进度条 |
| `macros` | 自定义文本宏（见第七节） |
| `pause_game` | 打开书时是否暂停游戏 |

## 四、分类（Category）模板

顶层分类：

```json
{
  "sortnum": 0,
  "name": "pasterdream.seniors_dream.category.rules",
  "description": "pasterdream.seniors_dream.category.rules.desc",
  "icon": "pasterdream:debug_sword"
}
```

子分类（多一个 `parent`）：

```json
{
  "sortnum": 4,
  "name": "pasterdream.seniors_dream.category.rules_shadow_difficulty",
  "description": "pasterdream.seniors_dream.category.rules_shadow_difficulty.desc",
  "icon": "pasterdream:shadow_desk",
  "parent": "pasterdream:rules"
}
```

字段说明（官方）：

| 字段 | 必填 | 说明 |
|------|------|------|
| `name` | ✅ | 分类名（翻译键） |
| `description` | ✅ | 分类描述（翻译键，显示在分类主页，可格式化） |
| `icon` | ✅ | 图标：物品 ID 或 `.png` 纹理路径 |
| `parent` | ❌ | 父分类 ID（子分类才需要，形如 `命名空间:名字`） |
| `sortnum` | ❌ | 排序（越小越靠前） |
| `flag` | ❌ | **配置开关表达式**（config flag），决定该分类是否存在 |
| `secret` | ❌ | `true` 时解锁前完全不显示 |

> **分类 ID = 相对 `categories/` 的路径去掉 `.json`**。子分类路径用 `/`：`categories/foretold_dream/buffs.json` → ID `foretold_dream/buffs`。

## 五、词条（Entry）模板

普通词条：

```json
{
  "sortnum": 0,
  "name": "pasterdream.seniors_dream.entry.san",
  "icon": "pasterdream:garland",
  "category": "pasterdream:rules",
  "pages": [
    {
      "type": "patchouli:text",
      "text": "pasterdream.seniors_dream.entry.san.page0"
    }
  ]
}
```

带 spotlight + 进度锁的词条（灯影之下物品示例）：

```json
{
  "sortnum": 3,
  "name": "pasterdream.seniors_dream.entry.shadow_sword",
  "icon": "pasterdream:shadow_sword",
  "category": "pasterdream:lamp_shadow_world/items",
  "advancement": "pasterdream:story/enter_lamp_shadow_world",
  "pages": [
    {
      "type": "patchouli:spotlight",
      "item": "pasterdream:shadow_sword",
      "text": "pasterdream.seniors_dream.entry.shadow_sword.page0"
    },
    {
      "type": "patchouli:text",
      "text": "pasterdream.seniors_dream.entry.shadow_sword.page1"
    }
  ]
}
```

字段说明（官方）：

| 字段 | 必填 | 说明 |
|------|------|------|
| `name` | ✅ | 词条名（翻译键） |
| `category` | ✅ | 所属分类 ID（含路径） |
| `icon` | ✅ | 图标：物品 ID 或 `.png` 纹理路径 |
| `pages` | ✅ | 页面数组（见第六节） |
| `advancement` | ❌ | **进度锁**：达成进度后才显示该词条 |
| `flag` | ❌ | 配置开关表达式（config flag） |
| `sortnum` | ❌ | 排序（相同 sortnum 按字母序） |
| `priority` | ❌ | `true` 时斜体置顶显示 |
| `secret` | ❌ | `true` 时解锁前隐藏，且不计入完成度 |
| `read_by_default` | ❌ | `true` 时不显示未读 `(!!)` 标记 |
| `turnin` | ❌ | 阅读后需完成的进度（任务式词条） |
| `entry_color` | ❌ | 分类里该词条链接的颜色（`RRGGBB`） |
| `extra_recipe_mappings` | ❌ | 额外物品 → 页码映射，供快捷查询 |

> **词条 ID = 相对 `entries/` 的路径去掉 `.json`**。路径与分类路径对应：`entries/foretold_dream/buffs/rest.json` → ID `rest`，属于分类 `foretold_dream/buffs`。

## 六、页面类型（Page Types）

页面是 `pages` 数组里的对象，必须带 `"type"`。所有页面类型通用的可选字段：

- `advancement`：单页进度锁（达成进度才显示该页）
- `flag`：单页配置开关
- `anchor`：锚点，供 `$(l:entryid#anchor)` 内部链接跳转

### 6.1 纯文本 `patchouli:text`

```json
{
  "type": "patchouli:text",
  "title": "可选标题",
  "text": "pasterdream.seniors_dream.entry.san.page0"
}
```

- `text`：正文（必填，可格式化）。
- `title`：可选标题（首屏不能用 `title`）。
- 简写：`pages` 数组里直接写字符串，等价于一个 text 页。

### 6.2 物品 spotlight `patchouli:spotlight`

```json
{
  "type": "patchouli:spotlight",
  "item": "pasterdream:shadow_sword",
  "text": "pasterdream.seniors_dream.entry.shadow_sword.page0"
}
```

- `item`：必填。可以是单个物品 ID 字符串、逗号分隔的多物品/标签（`"minecraft:diamond_sword,tag:minecraft:axes"`）、或原版 ingredient 对象（`{"item": "..."}` / `{"tag": "..."}`）。
- `title`：自定义标题（默认用物品名）。
- `link_recipe`：`true` 时该页可被 shift 点击跳转（推荐用于非常规合成说明）。
- `text`：物品下方的说明文字。

### 6.3 图片 `patchouli:image`

```json
{
  "type": "patchouli:image",
  "images": ["pasterdream:textures/patchouli_books/seniors_dream/en_us/entries/rules/san_amount_bar.png"],
  "text": "pasterdream.seniors_dream.entry.san.page1"
}
```

- `images`：纹理路径数组（多张时出现左右翻页箭头）。
- `title`：标题。
- `border`：默认 `false`，设为 `true` 才加边框（铺满整张画布时建议加）。
- `text`：图片下方的说明。
- 官方建议：图片文件 256×256，内容只放在**左上 200×200** 区域（以 0.5 倍缩放渲染）。

### 6.4 合成 `patchouli:crafting`

```json
{
  "type": "patchouli:crafting",
  "recipe": "pasterdream:hellfire_sword",
  "text": "pasterdream.seniors_dream.entry.inferno_sword.page0"
}
```

- `recipe`：主配方 ID（必填）；`recipe2`：副配方（可选）。
- `title`、`text` 可选。

### 6.5 熔炉系 `patchouli:smelting`（另有 `blasting` / `smoking` / `campfire` / `stonecutting`）

```json
{
  "type": "patchouli:smelting",
  "recipe": "pasterdream:titanium_ingot",
  "text": "..."
}
```

字段同 `crafting`（`recipe` / `recipe2` / `title` / `text`）。

### 6.6 多方块 `patchouli:multiblock`

```json
{
  "type": "patchouli:multiblock",
  "multiblock_id": "pasterdream:some_structure",
  "name": "结构名",
  "text": "..."
}
```

- `name`：必填，结构名（显示为标题）。
- `multiblock_id`（模组内注册的 ID）或 `multiblock`（内联对象）二选一。
- `enable_visualize`：默认 `true`，控制是否显示「可视化」按钮。
- `text`：结构下方的说明。

### 6.7 实体 `patchouli:entity`

```json
{
  "type": "patchouli:entity",
  "entity": "minecraft:chicken",
  "scale": 1.0,
  "text": "..."
}
```

- `entity`：实体 ID（必填，可带 NBT）。
- `scale` / `offset` / `rotate` / `default_rotation`：展示缩放 / 偏移 / 是否旋转 / 默认角度。
- `name`、`text` 可选。

### 6.8 其他（本项目暂未使用，备用）

| 类型 | 关键字段 | 说明 |
|------|---------|------|
| `patchouli:link` | `url`、`link_text`、`text` | 网页链接按钮 |
| `patchouli:relations` | `entries`、`title`、`text` | 相关词条跳转 |
| `patchouli:quest` | `trigger`、`title`、`text` | 任务页（配合 entry 的 `turnin`） |
| `patchouli:empty` | `draw_filler` | 空白页（`draw_filler:false` 彻底空白） |

## 七、文本格式宏（官方）

Patchouli 正文用 `$()` 宏做富文本。项目实际用到 + 官方常用：

| 宏 | 含义 |
|----|------|
| `$(br)` | 单行换行 |
| `$(br2)` | 两行换行（新段落） |
| `$(li)` / `$(li2)` / `$(li3)` | 列表项 / 嵌套列表 |
| `$(#rrggbb)` / `$(#rgb)` | 十六进制颜色（如 `$(#ff0000)` 红） |
| `$(0-f)` | 原版颜色代码（如 `$(6)` 金色） |
| `$(l)` / `$(m)` / `$(n)` / `$(o)` / `$(k)` | 加粗 / 删除线 / 下划线 / 斜体 / 乱码 |
| `$(l:ID)` | 内部链接（跳转词条/分类） |
| `$(l:entryid#anchor)` | 链接到带 anchor 的某页 |
| `$(l:https://...)` | 外部链接 |
| `$(playername)` | 玩家名 |
| `$(k:键名)` | 显示按键绑定 |
| `$(t:提示文字)` ... `$(/t)` | 悬停提示 |
| `$(c:/命令)` ... `$(/c)` | 点击执行命令 |
| `$()` | 清除格式 |

官方默认别名宏：`$(bold)`→`$(l)`、`$(strike)`→`$(m)`、`$(italic)`/`$(italics)`→`$(o)`、`$(obf)`→`$(k)`、`$(p)`/`$(2br)`→`$(br2)`、`<br>`→`$(br)`、`$(item)`→`$(#b0b)`（紫色）、`$(thing)`→`$(#490)`（绿色）——后两者是**颜色高亮**，用于突出物品名/概念，不是渲染图标。

> **百分号转义**：正文里出现 `%` 时写 `%%`。这是 Minecraft 自身的 bug——要显示一个 `%`，有时必须写 `%%` 才能正确渲染（并非 Patchouli 官方语法）。

## 八、语言键约定

所有文本走翻译键，键名规则：

| 类型 | 键格式 | 示例 |
|------|--------|------|
| 分类名 | `pasterdream.seniors_dream.category.<id>` | `...category.rules` |
| 分类描述 | `pasterdream.seniors_dream.category.<id>.desc` | `...category.rules.desc` |
| 词条名 | `pasterdream.seniors_dream.entry.<id>` | `...entry.san` |
| 页面 | `pasterdream.seniors_dream.entry.<id>.page<N>` | `...entry.san.page0` |

- 子分类的键把路径 `/` 换成 `_`：分类 `foretold_dream/buffs` → 键 `category.foretold_dream_buffs`。
- 语言键定义在 `ModZhCnLangProvider.java`（datagen 源），生成到 `src/generated/.../lang/zh_cn.json`（gitignore，`runData` 重新生成）。

## 九、图标物品约定

- 普通方块/物品：直接用注册 ID（如 `pasterdream:shadow_desk`、`pasterdream:nightmare_fuel`）。
- **buff 图标**：每个 buff 单独注册一个 `*_buff_icon` 物品，例如：
  - 注册：`ModItems.java` 里 `ITEMS.register("rest_icon", () -> new Item(new Item.Properties()))`
  - 模型：`ModItemModelsProvider.java` 里 `basicItem(ModItems.REST_ICON.get())`
  - 纹理：`textures/item/<id>_buff_icon.png`（通常直接复制 `textures/mob_effect/<effect>.png`）
  - 名称：语言文件里补 `暗影沉默图标` / `Shadow Silence Icon` 等

图标对应的物品必须已注册，否则帕秋莉里图标显示不出来。

## 十、项目约定汇总

1. **命名**：分类 / 词条 ID 一律 `snake_case`、全小写、语义化（如 `shadow_difficulty`、`broken_note`）。
2. **排序**：`sortnum` 按 `.md` 里出现顺序从 0 递增（分类内、子分类内各自独立排序）。
3. **进度锁**：灯影之下的物品词条统一带 `"advancement": "pasterdream:story/enter_lamp_shadow_world"`。
4. **双语**：`zh_cn` 与 `en_us` 的 JSON 文件内容一致（都引用翻译键）；翻译文本只维护在 `zh_cn`。
5. **风味文字**：`——xxx` 结尾的引言，独立成页，或拼在页尾用 `$(br2)` 分隔。

---

## 十一、新增一个词条的检查清单

1. 在 `旧梦归引.md` 对应分类下加 `## 词条名` + `[icon=...]` + 正文。
2. 确认图标物品已注册（见第九节）。
3. 在 `zh_cn` 与 `en_us` 的 `entries/<分类路径>/<词条id>.json` 各建一份（内容一致）。
4. 在 `ModZhCnLangProvider.java` 补词条名 + 各页 `page<N>` 键。
5. 若涉及进度锁，补 `advancement` 字段。
6. （本地）跑 `runData` 或手动更新 `src/generated/.../lang/zh_cn.json`。
7. 若词条带 spotlight / 图片，确认物品 / 纹理存在。
