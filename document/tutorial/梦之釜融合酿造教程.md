# 梦之釜（融梦釜）融合酿造完全教程

> 适用版本：PasterDream: Reborn（Forge 1.20.1）
>
> 本文讲解梦之釜的**药水模块**：基础酿造、融合、勾兑、装瓶与自动化。原版酿造台能做的，这里基本都能做，而且**不需要下界疣**。

## 一、这套系统是什么

梦之釜是本模组的炼金机器。放入**染梦果**当引子、放入原版酿造材料当催化剂，再配合**融梦涌泉**，就能把普通药水“融合”成多效果药水，或把药水补满成更多口数。

一句话总结流程：

> **染梦果 + 酿造材料 → 基础药水 → 加融梦涌泉 + 新效果 → 融合药水 → 装进灵药瓶喝**

药水以**流体**形式存在釜内，计量单位是 mB（毫桶）。**每 250 mB 算“一口”**，喝一口结算一次完整效果。

## 二、准备材料

| 材料 | 用途 | 获取方式                                      |
|------|------|-------------------------------------------|
| **梦之釜** | 主体机器 | 探索**染梦世界树结构**，釜旁书桌上还有一本《融梦釜与融梦炼金术》笔记      |

## 三、界面与槽位

右键梦之釜打开界面。下方表格中的**槽位索引**与代码中的槽位编号一致，方便对照 JEI、自动化与排错。

| 槽位索引 | 界面位置 | 槽位内容 | 容量 / 说明 |
|:---:|---|---|---|
| **物品 0** | 上方左格 | 染梦果 | 必需；不放染梦果则不走药水模块 |
| **物品 1** | 上方中格 | 催化剂 | 原版酿造材料，决定产出效果 |
| **物品 2** | 上方右格 | 增强剂 | 红石粉或荧石粉，可留空 |
| **物品 3** | 中部偏下 | 原模组配方输出 | 只出不进；药水模块不使用此格 |
| **流体 0** | 右侧液格 | 融梦涌泉 | 2000 mB；旁边有竖向液位条 |
| **流体 1** | 左侧液格 | 基底药水 | 8000 mB；融合时读取此槽 |
| **流体 2** | 中间液格 | 输出槽 | 1000 mB；成品药水产出处 |

操作按钮位于界面下方（物品槽下方居中）。

**液体怎么进出？** 和普通槽位不同：

- 鼠标**拿起**一个流体容器（桶、灵药瓶等），**左键**点液体格 = 把格里的液体装进容器；
- **右键**点液体格 = 把容器里的液体倒进该格。

## 四、基础酿造（Brew）

把普通材料变成药水，250 mB 起。

**条件**

- 流体槽 1（左侧基底）**必须为空**；
- 物品槽 0 放**染梦果**；
- 物品槽 1 放催化剂；
- 物品槽 2 可选红石 / 荧石；
- 流体槽 2（输出）为空。

**步骤**

1. 物品槽 0 放染梦果，物品槽 1 放糖；
2. 点按钮；
3. 输出槽（流体 2）得到 **250 mB 速度药水**。

**原理**：系统内部直接以“粗制的药水”为起点，所以**不需要先酿粗制药水**，放材料即可。催化剂凡是能在原版酿造台里把粗制药水变成效果药水的，都有效。

**增强剂**

- 物品槽 2 放**红石**：延长有时长的效果（瞬间类无效）；
- 物品槽 2 放**荧石**：提升效果等级（瞬间类也能强化）。

## 五、融合（Fuse）——本文重点

把**已有药水**和**新效果**合成一瓶多效果药水。

**条件**

- 流体槽 1（左侧基底）有 **≥250 mB 成品药水**；
- 流体槽 0（右侧泉涌）有 **≥250 mB 融梦涌泉**；
- 物品槽 0 放染梦果，物品槽 1 放新催化剂，物品槽 2 可选增强剂；
- 流体槽 2（输出）为空；
- 融合后总量不超过 1000 mB（即左侧药水最多 750 mB）。

**结果**

- 输出量 = 左侧药水量 + **250 mB**；
- 效果 = 左侧原有全部效果 + 新酿出的效果；
- **同一种效果取等级较高者**，不同效果直接叠加；
- 每种效果保留自己的等级与时长；
- 消耗右侧 250 mB 泉涌，左侧清空。

**操作步骤**

1. 先用基础酿造做出一瓶药水（例如 250 mB 速度）；
2. 拿**空灵药瓶**，左键点流体槽 2（输出），把药水装进瓶子；
3. 再右键点**流体槽 1（左侧基底）**，把瓶子里的药水倒进左侧——这一步是把药水从输出搬到“基底槽”；
4. 用**融梦涌泉桶**右键点**流体槽 0（右侧）**，倒入泉涌；
5. 物品槽 0 放染梦果，物品槽 1 放烈焰粉（力量），物品槽 2 可放红石 / 荧石；
6. 点按钮 → 得到 **500 mB 速度 + 力量** 融合药水。

> 【图片位 5：融合前后的界面状态对比】

**示例：速度 + 力量**

| 项目 | 数值 |
|------|------|
| 左侧基底（流体 1） | 250 mB 速度 |
| 右侧泉涌（流体 0） | 250 mB |
| 新催化剂（物品 1） | 烈焰粉（力量） |
| 产出（流体 2） | 500 mB，速度 + 力量 |

> 小技巧：如果同一种效果想升级，就在物品槽 2 放荧石再融合同效果催化剂，系统会保留等级更高的那一条。

## 六、勾兑（Blend）——补量与合并

**勾兑不使用物品**，只处理液体。

**条件**

- 物品槽 0、1、2 **全部清空**；
- 流体槽 1 是成品药水；
- 流体槽 0 是**融梦涌泉**，或**效果列表完全相同的药水**（效果种类和等级一致，时长不比较）；
- 流体槽 2（输出）为空。

**效果**

- 总量 = 左侧 + 右侧，上限 1000 mB；
- **效果与每口时长完全不变**；
- 用泉涌勾兑 = 把药水补满到 1000 mB，口数变多；
- 用同效果药水勾兑 = 两瓶并成一瓶。

**示例**：500 mB 夜视 + 500 mB 泉涌 → 1000 mB 夜视（4 口）。

**示例**：两个 250 mB 速度 → 500 mB 速度。

> 注意：勾兑时右侧若是药水，效果列表必须与左侧**完全一致**，否则提示“效果不一致，无法勾兑”。

## 七、装瓶与饮用

**装瓶**：手持**空灵药瓶**，直接**右键梦之釜方块**或打开界面用空灵药瓶**右键流体槽** 2 ，流体槽 2 里的药水就会灌进瓶子，最多 1000 mB。

- 输出槽不足 1000 mB 时，装多少算多少；
- 输出槽剩余药水留在釜里；
- 创造模式不消耗空瓶。

**饮用**：手持灵药瓶长按右键。

- 每口消耗 **250 mB**，结算一次完整效果；
- 一瓶 1000 mB = **4 口**；
- 不足 250 mB 时按比例缩减效果时长；
- 喝完瓶子**不会消失**，可以继续装填。吐槽:曾经有过喝完瓶子消失的BUG

## 八、自动化思路

- **物品输入**：漏斗 / 管道把染梦果、催化剂、增强剂送入物品槽 0 / 1 / 2；物品槽 3 只出不进。
- **液体输入**：釜的输入罐会**先尝试流体槽 0（泉涌）再尝试流体槽 1（基底）**。所以自动化时建议**先灌泉涌**，这样药水就不会误入泉涌罐；也可以直接往指定罐输。
- **液体输出**：只能从流体槽 2（输出）抽取，用管道接出即可。
- **触发**：给釜一个红石脉冲（上升沿）就会执行一次，和界面按钮等效。

## 九、常见错误速查

| 提示 | 原因 | 解决 |
|------|------|------|
| 左槽必须为空才能酿造 | 流体槽 1 还有液体 | 先装瓶 / 抽空 |
| 无效催化剂 | 该物品不能把粗制药水变成效果药水 | 换原版酿造材料 |
| 该催化剂不支持此增强剂 | 例如给瞬间治疗效果加红石 | 去掉增强剂或改荧石 |
| 增强剂冲突，请二选一 | 物品槽 1 和物品槽 2 放了不同增强剂 | 只留一种 |
| 输出槽不为空 | 上次成品没取走 | 先装瓶或抽走 |
| 基底药水不足250ml，无法融合 | 流体槽 1 少于 250 mB | 先补足 |
| 融合需要融梦涌泉 | 流体槽 0 没有 ≥250 mB 泉涌 | 倒入泉涌 |
| 容量上限1000ml | 融合后超过 1000 mB | 左侧留 ≤750 mB |
| 效果不一致，无法勾兑 | 两瓶药水效果或等级不同 | 只用泉涌或同效果药水 |
| 输出槽没有成品药水，无法装瓶 | 输出为空 | 先酿造 / 融合 |
