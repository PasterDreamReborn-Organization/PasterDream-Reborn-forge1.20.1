# 暗影难度系统

## 概述

暗影难度系统控制模组中所有暗影生物的数值强度、特殊行为和低理智生成。设计灵感来自《饥荒》(Don't Starve) 的理智-暗影生物机制。

难度分为三层，优先级从高到低：

1. **个人覆盖** — 通过命令写入玩家 persistent data，仅对该玩家生效
2. **默认玩家暗影难度** — `playerShadowDifficulty` gamerule，新玩家无覆盖时使用
3. **世界暗影难度** — `shadowDifficulty` gamerule，仅用于实体无玩家上下文时的回退

创建世界菜单中可分别配置两个 gamerule 的默认值。

## 核心入口

### 命令

#### /pasterdreamdebug shadowDifficulty

```
# 设置默认玩家暗影难度 (playerShadowDifficulty gamerule)
/pasterdreamdebug shadowDifficulty default <very_easy|easy|normal|hard>

# 设置世界暗影难度 (shadowDifficulty gamerule)
/pasterdreamdebug shadowDifficulty world <very_easy|easy|normal|hard>

# 设置单玩家难度覆盖（写入 persistent data）
/pasterdreamdebug shadowDifficulty player <player> <very_easy|easy|normal|hard>

# 查看当前难度信息
/pasterdreamdebug shadowDifficulty
```

**查看命令输出示例**（玩家执行）：
```
Player ShiLiuYinYu: Hard (困难) [personal override]
shadowDifficulty (world): Normal (普通) | playerShadowDifficulty (player default): Easy (简单)
```

**查看命令输出示例**（控制台执行）：
```
shadowDifficulty (world): Normal (普通) | playerShadowDifficulty (player default): Easy (简单)
```

#### /gamerule

```
/gamerule shadowDifficulty <0-3>        # 等同于 shadowDifficulty world
/gamerule playerShadowDifficulty <0-3>  # 等同于 shadowDifficulty default
```

#### 难度查询链

支持 tab 补全，显示难度名称。玩家有效难度按以下优先级确定：

```
个人覆盖 (persistent data "pasterdream.shadowDifficulty")
  → playerShadowDifficulty gamerule（默认玩家暗影难度）
    → 不适用：世界 shadowDifficulty gamerule 仅用于实体无玩家上下文时
```

### 难度等级

| 值 | 名称 | 血量 | 攻击 | 移速 | 战利品 | 特殊技能 | 刷怪区间 |
|----|------|:--:|:--:|:--:|:--:|:--:|------|
| 0 | 极简单 | 0.5x | 0.5x | 0.7x | 1.0x | 关闭 | 不刷 |
| 1 | 简单 | 1.0x | 1.0x | 1.0x | 1.0x | 开启 | 极低理智 (<0.2) |
| 2 | 普通 | 1.5x | 1.3x | 1.1x | 1.5x | 开启 | 中理智以下 (<0.6) |
| 3 | 困难 | 2.0x | 1.8x | 1.25x | 2.0x | 开启 | 中理智以下 (<0.825) |

### 属性倍率配置

```toml
shadowHealthMultipliers = [0.5, 1.0, 1.5, 2.0]
shadowAttackMultipliers = [0.5, 1.0, 1.3, 1.8]
shadowSpeedMultipliers = [0.7, 1.0, 1.1, 1.25]
shadowSpecialSkillsEnabled = ["false", "true", "true", "true"]

shadowGolemSkillDamage = 15.0     # 阴影傀儡 AoE 基础伤害
shadowHandSanDrain = 0.02         # 暗影之手 SAN 扣除基础值
shadowLootMultipliers = [1.0, 1.0, 1.5, 2.0]  # 战利品掉落倍率
```

## 系统架构

```
                    ┌──────────────────────────────┐
                    │  shadowDifficulty gamerule     │  ← 世界默认
                    │  + 玩家 PersistentData 覆盖    │  ← 每玩家覆盖
                    └──────────┬───────────────────┘
                               │
           ┌───────────────────┼───────────────────┐
           │                   │                   │
           ▼                   ▼                   ▼
   ┌───────────────┐   ┌──────────────┐   ┌───────────────┐
   │ 实体属性缩放   │   │ 特殊行为控制  │   │ 低理智刷怪     │
   │ (EntityJoin)  │   │ (Entity AI)  │   │ (PlayerTick)  │
   └───────────────┘   └──────────────┘   └───────────────┘
```

### 每玩家难度查询链

当有明确的 Player 上下文时（`PlayerTick`、`applyEffectTick`、实体直接触碰玩家等），直接使用该玩家的难度。当只有实体上下文时，按以下优先级查找：

```
源玩家 UUID tag (ShadowSourcePlayer)
  → 实体攻击目标 (getTarget)
    → 最近玩家 (64 格内)
      → 世界 gamerule 默认
```

---

### 层级 1：实体属性缩放

**触发点**：`ModMobSpawnEvents.onEntityJoinLevel()`

`#pasterdream:shadow_mob` 标签内实体加入世界时，按当前难度倍率修改基础属性：

- `MAX_HEALTH` × healthMultiplier
- `ATTACK_DAMAGE` × attackMultiplier
- `MOVEMENT_SPEED` × speedMultiplier

难度来源：`ShadowDifficultyHelper.getDifficultyContext(entity)`，优先使用低 SAN 刷怪时写入的 `ShadowSourcePlayer` UUID 对应玩家的难度。

仅对新生成实体生效（`loadedFromDisk() == false`）。

---

### 层级 2：特殊行为控制

#### 阴影傀儡 AoE (`ShadowGolemEntity`)

- 门控：使用 `getDifficultyContext(this)` 判定的难度等级，难度 0 时不触发
- 伤害：
  - 目标是 Player → 使用该玩家的难度计算伤害
  - 目标非 Player → 使用门控难度计算伤害
- **玩家免疫**：特殊技能关闭的玩家（难度 0）完全不受 AoE 伤害和击飞
- 伤害公式：`shadowGolemSkillDamage × attackMultiplier[难度]`

#### 暗影之手 SAN 抽取 (`ShadowHandEntity`)

- `doHurtTarget` / `playerTouch` 时，使用**被触碰玩家**的难度
- **玩家免疫**：特殊技能关闭的玩家不被抽取 SAN
- 扣除 SAN：`shadowHandSanDrain × attackMultiplier[玩家难度]`

#### 悲泣尖啸怨魂召唤 (`WailingShadowGhostEntity`)

- 门控：使用 `getDifficultyContext(this)` 判定的难度
- 难度 0：受击时不触发召唤
- 难度 1-3：正常召唤怨魂

#### 极低理智扣血 (`InsandBuffEffect`)

- 使用受效果玩家自己的难度
- 难度 0 + 创造/旁观：不扣血
- 难度 1-3：INSAND 效果 III 级 (amplifier≥2) 时每 tick 扣 1 HP

#### 恐怖尖喙吼叫 (`TerrorbeakEntity`)

- 门控：使用 `getDifficultyContext(this)` 判定的难度
- 难度 0：受击时不会触发吼叫
- 难度 1-3：正常吼叫（困惑、虚弱、减速 AoE + SAN 扣除）
- **玩家免疫**：特殊技能关闭的玩家不受吼叫 debuff 和 SAN 扣除影响
- 吼叫范围通过 `ModEntityTypeTags.SHADOW_MOB` 排除所有暗影生物

#### 战利品掉落加成 (`ModMobDrops`)

- **触发点**：`LivingDropsEvent`，对所有 `#pasterdream:shadow_mob` 标签内实体生效
- 难度来源：优先击杀者（`DamageSource.getEntity()` 是 Player），否则回退世界默认
- 每个掉落物以 `(shadowLootMultiplier[难度] - 1)` 的概率额外复制一份

| 难度 | 倍率 | 额外掉落概率 |
|:--:|:--:|:--:|
| 0（极简单） | 1.0 | 0%（无加成） |
| 1（简单） | 1.0 | 0%（无加成） |
| 2（普通） | 1.5 | 50% |
| 3（困难） | 2.0 | 100%（必定翻倍） |

### 层级 3：低理智刷怪

#### 触发机制 (`LowSanSpawnHandler`)

刷怪**完全独立于状态效果系统**。仅依据 SAN 比率判断，SAN 系统关闭时同步停止。**使用玩家个人难度**进行门控和概率计算。

```
PlayerTickEvent
├── LowSanSpawnHandler.onPlayerTick()     ← 读玩家 SAN ratio + 玩家个人难度 → 刷怪
│   ├── SanHelper.getIsSanEnabled() 门控
│   └── ShadowDifficultyHelper.tryLowSanSpawn()
│       ├── 内部使用 getDifficulty(player)
│       └── 生成实体时写入 ShadowSourcePlayer UUID tag
│
└── SanAuraHandler.onPlayerTick()         ← SAN 变化 + 状态效果
    └── 振奋 / 不振 / 恍惚 / 疯狂 效果
```

#### 区间边界

安全理智区间的下界（即中理智从哪开始）由 `lowSanSpawnHighThresholds` 按难度控制，其余边界沿用 SAN 阈值。各难度无空洞全覆盖。

```toml
# [极简单, 简单, 普通, 困难]
lowSanSpawnHighThresholds = [0.0, 0.2, 0.6, 0.825]
```

| 难度 |  安全理智  | 中理智 | 低理智 | 极低理智 |
|------|:------:|:--:|:--:|:--:|
| 极简单 |  ALL   | — (no) | — (no) | — (no) |
| 简单 |  ≥0.2  | — | — | <0.2 |
| 普通 |  ≥0.6  | 0.4~0.6 | 0.2~0.4 | <0.2 |
| 困难 | ≥0.825 | 0.4~0.825 | 0.2~0.4 | <0.2 |

"no" = 该难度下此区间概率为 0，不刷怪。

#### 各区间的概率与实体

每个区间有独立的**概率**（4 值列表，对应 4 个暗影难度）和**实体权重列表**。

| 区间 | 饥荒对照 |
|------|---------|
| 安全理智 | ≥82.5%，Mr. Skitts（不刷） |
| 中理智 | 40%~82.5%，Night Hands / 爬行恐惧可见 |
| 低理智 | 20%~40%，爬行恐惧频繁 |
| 极低理智 | <20%，恐怖尖喙 / 全暗影生物 |

```toml
# 各区间的默认配置（4 值 = [极简单, 简单, 普通, 困难]）

# 安全理智 — 全难度不刷
lowSanSpawnHighProbs = [0, 0, 0, 0]
lowSanSpawnHighEntities = []

# 安全理智下界（中理智从哪开始），每难度独立
lowSanSpawnHighThresholds = [0.0, 0.2, 0.6, 0.825]

# 中理智 — 上界随难度变化（见上表）
lowSanSpawnMediumProbs = [0, 0, 0.001, 0.002]
lowSanSpawnMediumEntities = ["pasterdream:weakeness_terrorbeak:0.15", "pasterdream:shadow_hand:0.3"]

# 低理智 (0.2~0.4) — 仅普通/困难刷
lowSanSpawnLowProbs = [0, 0, 0.002, 0.004]
lowSanSpawnLowEntities = ["pasterdream:weakeness_terrorbeak:0.4", "pasterdream:shadow_hand:0.2", "pasterdream:terrorbeak:0.1"]

# 极低理智 (<0.2) — 简单及以上刷
lowSanSpawnCriticalProbs = [0, 0.005, 0.005, 0.006]
lowSanSpawnCriticalEntities = [
    "pasterdream:crazy_terrorbeak:0.25",
    "pasterdream:terrorbeak:0.2",
    "pasterdream:weakeness_terrorbeak:0.15",
    "pasterdream:shadow_hand:0.15"
]
```

#### 生成限制

| 配置项 | 默认值 | 说明 |
|-------|:---:|------|
| `lowSanSpawnMaxLight` | 5 | 最大方块亮度，超过不生成（安全屋照明防刷） |
| `lowSanSpawnRadiusMin` | 7 | 距玩家最小距离（格） |
| `lowSanSpawnRadiusMax` | 12 | 距玩家最大距离（格） |
| `lowSanSpawnMaxNearby` | 2 | 周围最大暗影生物数（饥荒上限） |

生成条件：下方为完整固体方块，生成位及上方为空气，最多尝试 8 次随机位置。**生成时将触发玩家的 UUID 写入实体的 `ShadowSourcePlayer` persistent tag**，供后续属性缩放和行为判定使用。

#### 击杀回复理智

| 实体 | 击杀回复 SAN | 饥荒对照 |
|------|:---:|------|
| 虚弱恐怖尖喙 | +7 | Crawling Horror +15 |
| 恐怖尖喙 | +7 | Terrorbeak +33 |
| 疯狂恐怖尖喙 | +30 | — |

位于 `TerrorbeakEntity.die()`，仅击杀者为玩家且 SAN≤20 时触发。不受难度缩放。

## 每玩家存储方案

玩家个人难度覆盖存储在 `Entity.getPersistentData()` 中：

```
Key: "pasterdream.shadowDifficulty"
Value: int (0-3)
```

- 不存在该 key → 使用 `playerShadowDifficulty` gamerule 默认值
- 存在该 key → 使用覆盖值
- `ShadowDifficultyHelper.setPlayerDifficulty(player, tier)` 写入
- `ShadowDifficultyHelper.clearPlayerDifficulty(player)` 移除，恢复使用 gamerule 默认值
- `ShadowDifficultyHelper.hasPlayerOverride(player)` 查询是否有覆盖

选择 persistent data 而非 Capability 的理由：仅一个 int，不需要网络同步（仅服务端使用），不需要复杂生命周期管理。

## 低San视觉效果持久化

`/pasterdreamdebug lowsan` 的 overlay / jitter / sound 三开关通过世界 `SavedData` 持久化，重登自动恢复。

| 文件 | 作用 |
|------|------|
| `LowSanWorldData.java` | 世界级持久化 |
| `LowSanConfigSyncPacket.java` | 客户端同步 |
| `LowSanEffect.java` | 命令处理 + 调度 |
