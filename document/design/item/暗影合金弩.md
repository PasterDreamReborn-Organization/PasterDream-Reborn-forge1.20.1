# 暗影合金弩 设计文档

> 关联：`document/design/新内容列表.md`、`document/design/item/暗影合金工具.md`、`document/design/item/暗影合金盔甲.md`
> 系列：灯影之下 · 暗影合金系列（`world/item/shadowalloytool/`）
> 性质：**全新设计**（原模组无），不进 `ID映射表.md`

---

## 一、定位

- 暗影合金系列的**远程武器**，与暗影合金工具 / 盔甲同属灯影之下毕业线。
- 以原版弩为基础行为（装填 / 发射 / 烟花），叠加暗影合金系列的语言：**弹幕附加负面状态 + 低门槛高性价比火力**。
- 与暗影合金工具一致：**EPIC、防火、暗影合金锭修复**。

## 二、核心机制

| 机制 | 说明 |
|---|---|
| 可附魔无限 | 放开原版对弩的限制，允许附魔「无限」；**且实际生效**——装填 / 发射不消耗**普通箭矢**（仿原版弓的无限）。**药水箭 / 光谱箭 / 烟花不受无限影响，照常消耗**。 |
| 自带力量 III | 内置相当于原版**力量 III**的箭矢伤害加成；与附魔**力量 V 叠加**（等效等级相加：3 + 附魔等级）。 |
| 命中必施易伤 | 弩箭命中**除射手外**的生物（含玩家）必定施加 **10s 易伤**（复用 `ModEffects.VULNERABILITY`）。 |
| 命中随机负面 | 同一命中再随机施加**一项配置白名单内的 5s 负面效果**（等级 I）。 |
| 烟花群体生效 | 装填**含烟火之星的烟花**时，烟花爆炸伤害命中的所有生物同样触发上述易伤 + 随机负面（`FireworkRocketEntity` 逐个 `LivingEntity#hurt`）。 |
| 暗紫拖尾 | 弩箭使用自定义箭实体 `ShadowAlloyArrowEntity`，客户端绘制**暗紫色**三棱柱管拖尾（复用通用 `ArrowTrailRenderer`，颜色 `0xFF8E24AA → 0x008E24AA`）。光谱箭保留原版实体（无拖尾）以维持发光。 |

- 效果通过箭矢**持久数据标记**（`pasterdream:shadow_alloy_crossbow_arrow`）识别来源：只有本弩发射的箭矢触发，且仅在服务端结算。
- 「力量」指原版**力量附魔**（Power，箭矢伤害），非力量药水效果。

## 三、配置项（Config）

| 配置键 | 默认 | 说明 |
|---|---|---|
| `shadowAlloyCrossbowDebuffs` | `minecraft:slowness` / `mining_fatigue` / `blindness` / `weakness` / `poison` / `wither` / `levitation` / `pasterdream:confusion` / `pasterdream:bind` | 随机负面效果白名单（`modid:effect_id` 列表） |
| `shadowAlloyCrossbowDebuffDuration` | 100（5s） | 随机负面效果持续时间（tick） |
| `shadowAlloyCrossbowDebuffAmplifier` | 0（I 级） | 随机负面效果等级 |

- 易伤持续时间固定 **200 tick（10s）**，作为常量写在 `ShadowAlloyCrossbowHandler`。
- 白名单解析结果缓存于 `Config.getShadowAlloyCrossbowDebuffs()`（无效 / 未知 ID 跳过并告警），与卡莱调料瓶一致。

## 四、配方

- **类型**：合成台有序配方（无 NBT 保留）。
- **阵型**：

  ```
  a b a
  b c b
  d b d
  ```

  - `a` = 黑石棍 ×2
  - `b` = 暗影合金锭 ×4
  - `c` = 弩 ×1（原版 `minecraft:crossbow`）
  - `d` = 噩梦燃料 ×2

- **产物**：暗影合金弩 ×1。

## 五、联动

- 加入 `#pasterdream:lamp_shadow_weapon`：满套暗影合金盔甲「黑暗守望」时，本弩造成伤害 +30%（由 `ShadowAlloyArmorHandler` 结算，远程命中同样生效）。

## 七、待原型验证

- 力量 III + 力量 V 叠加后的实际箭矢伤害手感（当前按等效等级 8 套用原版力量公式）。
- 随机负面白名单的强度与「5s」是否过强 / 过弱。
- 无限附魔在冒险模式 / PvP 下的平衡性。

## 八、残余风险

1. **无限实现方式**：重写了装填逻辑（拷贝而非扣除箭矢）。需确认与「多重射击」的交互——无限与多重射击在原版互斥，但不排除其它模组绕过兼容检查。
2. **箭矢标记持久化**：命中判定依赖箭矢持久数据，跨存档 / 服务器重启由 Forge 持久数据机制保证。
3. **谓词注册遗漏风险**：自定义弩必须显式注册 `pull`/`pulling`/`charged`/`firework` 模型谓词，否则纹理不切换（已记入 `程序规范文档.md` 易犯错误记录）。
