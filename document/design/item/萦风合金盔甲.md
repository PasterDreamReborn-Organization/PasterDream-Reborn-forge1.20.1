## 一、定位

- **风之旅途毕业护甲**：融梦水晶护甲 → 萦风合金护甲。
- 与暗影合金同级：合成材料同样需要**击败 BOSS** 才能获得，故战斗性能**与暗影合金相当、略高于融梦水晶**。
- 获取方式：**精铸工坊工作台** 4 条配方，由**钛金护甲**升级：对应钛金部位 ×1 + 萦风合金升级套件 ×1 + 萦风合金锭 ×1 + 凝结之风 ×2 + 凝风铁锭 ×4 + 强化石 ×1 → 对应萦风合金护甲部位 ×1。
- 主题：**风 + 天候 + 游射**。单件提供机动性与战技循环，满套解锁「风雷之佑」——把天气变成自己的增益，并具备缓降与弹射物反制能力。

## 四、套装效果「风雷之佑」（满套）

满套时生效，天气是核心变量。天气判定：

- **晴朗**：`!level.isRaining()`
- **雨天**：`level.isRaining() && !level.isThundering()`
- **雷雨**：`level.isThundering()`
- **非晴朗**（雨天或雷雨）：`level.isRaining()`

| # | 子项 | 规则 | 实现落点 |
|---|---|---|---|
| 4.1 | **疾射** | 拉弓时间 −25%；弩箭装填时间 −25%（以玩家属性「拉弓与装填时间缩减 +25%」提供，其他内容也可通过该属性叠加） | 满套挂临时属性修饰器 `RANGED_CHARGE_TIME_REDUCTION` + Mixin（见 §六） |
| 4.2 | **避雷** | 免疫雷电伤害（`DamageTypes.LIGHTNING_BOLT`，含原版落雷/引雷三叉戟） | `LivingHurtEvent` / `LivingDamageEvent` 置 0 + 取消 |
| 4.3 | **风势** | **非晴朗**天气时，单件的移动速度与战技冷却增益**翻倍**（即每件 +10% 移速 / −10% 冷却，满套 +40% / −40%）。**仅作用于移速与冷却两项**，不影响防御 | 满套 + 非晴朗时额外挂一组临时属性修饰器（独立 UUID，逐 tick 判定增删） |
| 4.4 | **沐雨** | **雨天**受到伤害 **−10%**（最终减伤）；**雷雨**翻倍为 **−20%** | `LivingDamageEvent`（护甲/附魔结算之后）`amount *= 0.9 / 0.8` |
| 4.5 | **逆风** | 被弹射物命中时 **50% 概率弹开**（本次不受伤，弹射物被弹开且**归属不变**，仍属于原发射者） | 服务端判定 `ProjectileImpactEvent` / 伤害事件 |
| 4.6 | **缓降** | 下落途中**按住空格**可缓降（手感等同原版缓降效果：削弱重力、自然下沉），**持续消耗饥饿度** | `TickEvent.PlayerTickEvent` 服务端按原版缓降曲线削弱重力（每刻补回 0.07 重力缺口）+ `causeFoodExhaustion`；**不启用 `abilities.flying`**，规避“未开飞行被踢出” |

### 4.1 疾射（细节）

- 原版弓/弩的**蓄力进度、拉弓动画、弩瞄准动画、弓的 FOV 拉近**均读取 `getUseItemRemainingTicks()`。
- 属性：`ModAttributes.RANGED_CHARGE_TIME_REDUCTION`（`ranged_charge_time_reduction`），玩家属性，默认 `0`，**正值 = 时间缩减**，`0.25` 表示使用时长 ×0.75（等效速度 ×4/3）。范围 `[-0.95, 0.95]`，避免换算速度倍率 `1/(1-值)` 发散。满套时由 `FluffyWindAlloyArmorHandler` 逐 tick 挂/摘临时修饰器（`ADDITION`、独立 UUID），拆套立即失效。
- 实现：**Mixin `LivingEntity.updateUsingItem`（TAIL 注入）** —— 使用 `BowItem` / `CrossbowItem` 时读取该属性，每 tick 额外扣减 `值 / (1 - 值)` tick，小数部分累积到下一 tick，因此支持任意比例（不再局限于原来的每 3 tick 扣 1）。逻辑与动画**同步提速**。
- 在 TAIL 注入以保证原版 `--useItemRemaining == 0` 的完成判定不被跳过（不会漏掉自动装填/完成）。

### 4.5 逆风（细节）

- 定位：本质是「对弹射物的等效免疫 + 视觉弹开」，**不做伤害反打、不改归属**。
- 判定：弹射物命中满套玩家 → 掷 50%：
  - **触发**：本次**不对玩家结算伤害**（视同免疫弹射物伤害），弹射物被**弹开**（偏转/折射，而非反弹伤害），其**归属仍为原发射者**；被弹开后是否/如何命中其它实体，按原版常规结算。
  - **未触发**：放行，正常受伤。
- 仅对**弹射物类**生效（箭/弩箭/雪球/鸡蛋/三叉戟/烟花等）；爆炸/法术类（火球、凋灵之首等）可配置是否纳入。
- 弹开的具体表现（偏转方向、是否保留原速度、`AbstractArrow` 是否落回可拾取等）待原型定。

### 4.6 缓降（细节）

- 条件：满套 + `deltaMovement.y < 0`（下落中）+ 玩家按住跳跃键 + 饥饿度足够。
- 行为：**复刻原版缓降（Slow Falling）的物理**——原版在 `LivingEntity.travel` 中把空中重力由 `0.08` 降为 `0.01`，本套装每刻把正常重力多扣掉的 `0.07` 补回 `deltaMovement.y`，使下落速度沿原版缓降曲线平滑收敛（终端速度约 `-0.49` 格/刻），**不做速度钳制、不留横向惯性补偿**；横向按原版空中摩擦（×0.91）自然衰减，纵向平滑减速。松开跳跃、落地或饥饿耗尽即恢复正常。
- **客户端/服务端各自本地结算**：缓降物理由 `FluffyWindAlloyArmorHandler#applySlowFall` 在两侧分别执行（客户端仅在 `isLocalPlayer()` 且本地跳跃键状态为真时结算），因此**不写 `hurtMarked`**——原版 `ServerEntity` 遇到 `hurtMarked` 会向本人补发整向量 `ClientSetEntityMotionPacket`，逐 tick 覆盖客户端横向速度造成突变。本地结算使横向速度完全不受同步干扰；纵向 `moved wrongly` 判定在原版 `handleMovePlayer` 中已被清零，不会触发回拉。
- 消耗：仅服务端 `causeFoodExhaustion`（量级参照疾跑，原型定），客户端不重复消耗；饥饿度不足以支撑时两侧均不再缓降。
- **安全**：不得调用 `abilities.flying = true`（服务端会判定非法飞行并踢出）。纯靠改写 `deltaMovement` 复刻原版缓降重力实现；两侧均 `fallDistance = 0` 避免摔落伤害。
- 跳跃输入：客户端本地写入 `NBT_HOVER_JUMP` 并经 `WindHoverInputPacket` 同步服务端（服务端 1.20.1 仅在骑乘时收到跳跃输入），两侧读取同一标记。

## 五、模型与骨骼约定

- geo：`assets/pasterdream/geo/fluffy_wind_alloy_armor.geo.json`
- 纹理：`assets/pasterdream/textures/item/armor/fluffy_wind_alloy_armor.png`（128×128，cutout）
- 8 根约定骨骼（GeckoLib `GeoArmorRenderer` 按名抓取）：`armorHead` / `armorBody` / `armorRightArm` / `armorLeftArm` / `armorRightLeg` / `armorLeftLeg` / `armorRightBoot` / `armorLeftBoot`
- 6 根顶层容器骨 `bipedHead` / `bipedBody` / `bipedRightArm` / `bipedLeftArm` / `bipedRightLeg` / `bipedLeftLeg`（无 `parent`）
- `armor*` 的 pivot 固定为标准关节位（头/身 `[0,24,0]`、右臂 `[-5,22,0]`、左臂 `[5,22,0]`、右腿/靴 `[-1.9,12,0]`、左腿/靴 `[1.9,12,0]`）
- **注意**：源模型腿部/靴子左右标注反了，已按实际坐标纠正（`armorRight*` ← −X 侧）。
- **裙甲（`waist` / `LeftWaist` / `RightWaist`）归属护腿件**：源模型里 `waist` 是 `Root` 的直接子级（与 body 平级），搬运时初版误挂到 `armorBody`，导致裙甲只在胸甲上出现。现改为挂在顶层容器 `bipedBody` 下（`bipedBody` 与 `armorBody` pivot 相同，几何不变），并在 `FluffyWindAlloyArmorRenderer#applyBoneVisibilityBySlot` 里覆写为「仅 `LEGS` 槽可见」。因骨不在 `armorRightLeg`/`armorLeftLeg` 子树下，裙甲**不随腿摆动**（保持源模型相对躯干静止的表现）。参见 `client-rendering` skill「护甲骨骼与槽位可见性」。
- 无独立动画，空 idle 动画文件占位。

## 八、待原型验证 / 残余风险

1. **弹射物弹开**：当前用 `ImpactResult.SKIP_ENTITY`（视同对弹射物免疫穿透，归属不变），非“物理弹回”；爆炸/法术类未纳入，是否只限箭类待定。
2. **疾射表现**：已统一加速使用计时器，弓/弩的逻辑与动画（拉弓、装填、FOV、第三视角弩蓄力）同步提速；第三视角弓原版仅有姿势、无拉弓幅度动画。
3. **缓降手感**：跳跃键经自定义包（`WindHoverInputPacket`）同步、客户端本地写入同一 NBT 标记；饥饿消耗 `0.05/刻` 为占位，待调。重力缺口 `0.07` 已对齐原版缓降（`0.08 → 0.01`），下沉曲线与原版一致；客户端/服务端各自本地结算，横向速度不受速度同步干扰。
4. **免疫雷电边界**：是否包括玩家自己触发的连锁闪电（如萦风雷矛/暗影合金弩效果）——按设计应只免“受到的”雷电伤害。
5. **与既有风系效果叠加**：顺风/逆风（`tailwind`/`deadwind`）、防风（`windproof`）与本套共存时的数值上限。
6. **面板数值**：耐久 46 / 附魔性 22、满套 +40% 移速 / -40% 冷却，待 `runClient` 评估是否过强。
