# 暗影合金盔甲 设计文档

> 状态：**测试中 / 待换模型**（临时注册，非最终设计）
> 关联：`document/design/新内容列表.md`
> 实现：`world/item/armoritem/ShadowAlloyArmorItem.java`、`ShadowAlloyArmorModel.java`、`client/renderer/ShadowAlloyArmorRenderer.java`、`client/ShadowAlloyArmorSkinHider.java`

---

## 一、当前状态

- 已注册 4 件：`shadow_alloy_helmet` / `_chestplate` / `_leggings` / `_boots`
- 材质：`ModArmorMaterials.SHADOW_ALLOY`
- 渲染：GeckoLib GEO，**四件共用**一个模型，按约定骨骼名分槽裁剪，无独立动画
- **无配方、无被动、无数值设计**，纯空壳，仅用于验证渲染链路

## 二、模型与骨骼约定

- geo：`assets/pasterdream/geo/shadow_alloy_armor.geo.json`
- 纹理：`assets/pasterdream/textures/item/armor/shadow_alloy_armor.png`（128×128，二值 alpha，cutout）
- 8 根约定骨骼（GeckoLib `GeoArmorRenderer` 按名抓取）：`armorHead` / `armorBody` / `armorRightArm` / `armorLeftArm` / `armorRightLeg` / `armorLeftLeg` / `armorRightBoot` / `armorLeftBoot`
- 6 根顶层容器骨 `bipedHead` / `bipedBody` / `bipedRightArm` / `bipedLeftArm` / `bipedRightLeg` / `bipedLeftLeg`（**无 `parent`**，顶层骨不能引用不存在的骨）
- `waist` / `group2` / `group3` 挂在 `armorBody` 下（跟随胸甲显隐）
- 模型坐标对齐原版玩家；`armor*` 的 pivot 已改为标准关节位

## 三、已知问题

- **穿模**：建模时未考虑玩家皮肤外层，部分网格与玩家**内层皮肤等大甚至更小**（如头部主立方体 8×8×8，与原版内层头完全一致 → z-fighting；外层 `hat` / `jacket` / `pants` 直接穿出）。
- **临时规避**：`ShadowAlloyArmorSkinHider` 在 `RenderPlayerEvent.Pre/Post` 里隐藏玩家对应部位：
  - 头盔 → `head` + `hat`
  - 胸甲 → `body` + 双臂 + `jacket` / 左右袖
  - 护腿 → 双腿 + 左右裤脚
  - 靴子 → 无（玩家无独立脚部件，暂不隐藏，仍会与小腿轻度穿模）
- 该规避**代价大**：头盔下看不到脸，且为共享 `PlayerModel` 加了一层成对改可见性的状态，属于补丁。

## 四、后续计划（换模型时）

1. 重新建模：网格加 `inflate`（至少按原版盔甲 0.5 起，或直接比玩家外层皮肤略大），避免 z-fighting 与穿出。
2. 用标准 `biped*`（顶层无 parent）+ `armor*` 结构导出。
3. **换模型后删除 `ShadowAlloyArmorSkinHider` 及其实例化的事件订阅**。
4. 若新材质含半透明像素（0 < alpha < 255），在 `ShadowAlloyArmorRenderer` 覆写 `getRenderType` 返回 `RenderType.entityTranslucent(...)`；二值 alpha 保持默认 `entityCutoutNoCull` 即可。
5. 补齐正式设计：面板数值、套装被动、配方、稀有度、tooltip，并登记 `新内容列表.md` / `ToolTips文档.md`。
