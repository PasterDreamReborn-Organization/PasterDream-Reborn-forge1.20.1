# 暗影合金盔甲 设计文档

> 状态：**测试中**（临时注册，非最终设计；已换用第二版模型）
> 关联：`document/design/新内容列表.md`
> 实现：`world/item/armoritem/ShadowAlloyArmorItem.java`、`ShadowAlloyArmorModel.java`、`client/renderer/ShadowAlloyArmorRenderer.java`

---

## 一、当前状态

- 已注册 4 件：`shadow_alloy_helmet` / `_chestplate` / `_leggings` / `_boots`
- 材质：`ModArmorMaterials.SHADOW_ALLOY`
- 渲染：GeckoLib GEO，**四件共用**一个模型，按约定骨骼名分槽裁剪，无独立动画
- **无配方、无被动、无数值设计**，纯空壳，仅用于验证渲染链路

## 二、模型与骨骼约定

- geo：`assets/pasterdream/geo/shadow_alloy_armor.geo.json`
- 纹理：`assets/pasterdream/textures/item/armor/shadow_alloy_armor.png`（128×128，二值 alpha，cutout）
- 8 根约定骨骼（GeckoLib `GeoArmorRenderer` 按名抓取）：`armorHead` / `armorBody` / `armorRightArm` / `armorLeftArm` / `armorRightLeg` / `armorLeftLeg` / `armorRightBoot` / `armorLeftBoot`
- 6 根顶层容器骨 `bipedHead` / `bipedBody` / `bipedRightArm` / `bipedLeftArm` / `bipedRightLeg` / `bipedLeftLeg`（**无 `parent`**，顶层骨不能引用不存在的骨）
- `waist` / `group2` / `group3` 挂在 `armorBody` 下（跟随胸甲显隐）
- 模型坐标对齐原版玩家；`armor*` 的 pivot 固定为标准关节位（`armorHead`/`armorBody` `[0,24,0]`、`armorRightArm` `[-5,22,0]`、`armorLeftArm` `[5,22,0]`、`armor*Leg`/`armor*Boot` 右 `[-1.9,12,0]` / 左 `[1.9,12,0]`）

> **换模型流程**：把建模师导出的 Blockbench GEO 按上述骨骼名重命名并重挂父子（顶层骨不能引用不存在的骨），`armor*` 轴的 pivot 改为标准关节位，腿/靴子分别挂到对应 `biped*Leg`。`waist`/`group2`/`group3` 保留建模师给出的 pivot 与 rotation。

## 三、模型版本

- **v1**（初版）：网格按玩家**内层皮肤**等大建模（头部主立方体 8×8×8 与内层头完全一致 → z-fighting，外层 `hat`/`jacket`/`pants` 直接穿出）。曾用 `ShadowAlloyArmorSkinHider` 在 `RenderPlayerEvent.Pre/Post` 隐藏玩家对应部位临时规避（代价大：头盔下看不到脸）。
- **v2**（当前）：整体按 1.13 缩放重建，网格已越过玩家皮肤外层，穿模问题解决。**已删除 `ShadowAlloyArmorSkinHider` 及其实例化事件订阅。**

## 四、后续计划

1. 补齐正式设计：面板数值、套装被动、配方、稀有度、tooltip，并登记 `新内容列表.md` / `ToolTips文档.md`。
2. 若新材质含半透明像素（0 < alpha < 255），在 `ShadowAlloyArmorRenderer` 覆写 `getRenderType` 返回 `RenderType.entityTranslucent(...)`；二值 alpha 保持默认 `entityCutoutNoCull` 即可。
