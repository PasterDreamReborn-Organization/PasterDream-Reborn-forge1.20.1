## 一、定位

- **灯影之下毕业护甲**：融梦水晶护甲 → 暗影合金护甲。
- 灯影是**染梦下游**维度，且**唯一来源是重复挑战亚伦柯斯**（纯粹恐惧 → 暗影合金锭 → 合成），
  而融梦水晶护甲无需挑战 BOSS 即可获得，故战斗性能**略高于融梦水晶**在进度上成立。
- 获取方式：**合成台** 4 条普通有序配方（材料全部为暗影合金锭），与暗影合金工具同源。

## 三、套装效果「黑暗守望」（满套）

效果载体：`MobEffect dark_watch`（`DarkWatchEffect`），图标使用**头盔物品纹理**
（`textures/mob_effect/dark_watch.png`，由 `textures/item/shadow_alloy_helmet.png` 复制）。

| 子项 | 实现 |
|---|---|
| 灯影之下的武器造成伤害 +30% | `LivingHurtEvent`，主手物品带 `#pasterdream:lamp_shadow_weapon` 且满套 → `amount × 1.3` |
| 受到攻击获得 10s 反击，冷却 30s | `LivingHurtEvent`（受击方）；复用 `counter_attack`（下一次造成伤害 +50%）；冷却用玩家持久数据 `pasterdream:shadow_alloy_counter_ready` 存游戏刻时间戳，30s |
| 对暗影生物攻击 50% 最终减伤 | `LivingDamageEvent`（护甲/附魔结算之后，字面「最终减伤」）；攻击者 `EntityType` 属于 `#pasterdream:shadow_mob` 且满套 → `amount × 0.5` |

- 满套判定：`ShadowAlloyArmorItem.hasFullSet`（四件材质均为 `SHADOW_ALLOY`）。
- 「灯影之下的武器」标签 `#pasterdream:lamp_shadow_weapon` 成员：影蚀系列（匕首/镐/斧/锹/锄）
  + 暗影合金系列（镐/斧/锹/锄）+ 影刃，可后续扩充。

## 四、模型与骨骼约定

- geo：`assets/pasterdream/geo/shadow_alloy_armor.geo.json`
- 纹理：`assets/pasterdream/textures/item/armor/shadow_alloy_armor.png`（128×128，二值 alpha，cutout）
- 8 根约定骨骼（GeckoLib `GeoArmorRenderer` 按名抓取）：`armorHead` / `armorBody` / `armorRightArm` / `armorLeftArm` / `armorRightLeg` / `armorLeftLeg` / `armorRightBoot` / `armorLeftBoot`
- 6 根顶层容器骨 `bipedHead` / `bipedBody` / `bipedRightArm` / `bipedLeftArm` / `bipedRightLeg` / `bipedLeftLeg`（**无 `parent`**，顶层骨不能引用不存在的骨）
- `waist` / `group2` / `group3` 挂在 `armorBody` 下（跟随胸甲显隐）
- 模型坐标对齐原版玩家；`armor*` 的 pivot 固定为标准关节位（`armorHead`/`armorBody` `[0,24,0]`、`armorRightArm` `[-5,22,0]`、`armorLeftArm` `[5,22,0]`、`armor*Leg`/`armor*Boot` 右 `[-1.9,12,0]` / 左 `[1.9,12,0]`）

> **模型版本**：v1 按玩家内层皮肤等大建模（z-fighting，曾用 `ShadowAlloyArmorSkinHider` 规避，已删除）；
> v2（当前）整体按 1.13 缩放重建，网格越过皮肤外层，穿模问题解决。

## 七、残余风险

1. **增伤与减伤叠加**：+30% 走 `LivingHurtEvent`、50% 减伤走 `LivingDamageEvent`，两者不在同一阶段，无重复乘算问题。
2. **反击语义**：复用 `counter_attack`（下一次造成伤害 +50%），与反击戒指/转身衣装同源；若与其它反击来源同时触发，只有一层效果。
3. **冷却持久化**：冷却用玩家持久数据（游戏刻时间戳），跨维度/重登保留；创造模式不特殊豁免。
4. **标签范围**：`lamp_shadow_weapon` 目前含工具类（镐/斧/锹/锄），其攻击力同样 +30%，如需只限近战武器需再拆分。
