# 萦风雷矛 设计文档

> 关联：`document/design/新内容列表.md`、`document/design/item/ToolTips文档.md`、`document/design/ID映射表.md`
> 系列：风之旅途 · 萦风合金武器系列（`world/item/fluffywindalloy/`）

---

## 一、定位

- **风之旅途毕业级武器**，档次高于萦风合金剑。
- **正式归入萦风系列**：继承移速被动「雷随疾风」与「风卷掉落」。
- **核心身份**：近战 + 激流式突进 + 投掷连锁闪电，三形态一体的长柄武器。
- 获取方式暂缓；平衡优先靠**合成材料价格**，不靠冷却。

## 二、设计目标与辨识度

| | 萦风合金剑 | 萦风雷矛 |
|---|---|---|
| 距离 | 贴身近战 | 中远程投掷 |
| 雷电 | 单点 5 道落雷（定点/追踪） | 命中后**连锁跳跃** |
| 机动 | 疾风突进 | 投掷后**自动飞回** + 激流式突进 |
| 群伤 | 落雷小范围 | 连锁闪电多目标 |
| 手感 | 短、灵活 | 长、直、重 |

## 四、操作与形态

| 操作 | 形态 | 效果 |
|---|---|---|
| 左键 | 近战 | 物理伤害 + 附带雷伤（不连锁），吃移速，耗 1 耐久 |
| 普通右键（蓄力） | 突进 | 原版激流式前冲（冲量 + 自旋表现）+ 路径 AoE，基础冷却 3s、消耗 1.0 融梦能量；激流每级 +1s 冷却、+1.0 能量（各最多 +3） |
| Shift + 右键（蓄力） | 投掷 | 蓄满掷出**虚影**（本体留手），命中/落地触发连锁闪电后飞回；虚影返回前武器冷却（最长 10s），耗 1 耐久 + 1.0 融梦能量 |

- 两种蓄力**时长相同**；**形态在释放瞬间按 `player.isShiftKeyDown()` 判定**（蓄力中途切换潜行也生效）。
- 蓄力实现走 `getUseDuration` / `releaseUsing`。
- 突进**无限制**（不要求水/雨），冷却 3s，靠合成价格平衡。
- **两个战技形态各消耗 1.0 融梦能量**（`SKILL_ENERGY_COST`）；能量不足时 `use()` 直接失败并提示，不进入蓄力。

## 五、机制细节

### 5.1 近战
- 伤害吃移速：`伤害 = (1 + 移速) × 攻击力`，移速取 `max(移速属性, 瞬时移速)`（沿用 `FluffyWindAlloySwordItem:322`）。
- 命中额外附带 `攻击力 × 0.1` 雷电伤害（对应剑的「雷随疾风」附伤，**不连锁**）。
- 命中消耗 1 耐久。

### 5.2 突进（普通右键蓄力）
- **原版激流式突进**：复制 `TridentItem` 的激流逻辑——按准心方向 `push` 冲量 + `startAutoSpinAttack(20)` 自旋攻击 + 原版激流音效；地面释放时额外抬升 1.2 格。
- 冲量档位 `DASH_RIPTIDE_LEVEL`（默认 2）决定强度，绕开原版 `isInWaterOrRain` 限制（无限制可突进）。
- **伤害由自旋接触结算**（`applyDashOnTouch`）：原版自旋碰到目标时，把该次伤害替换为突进伤害（激流加成、横扫之刃溅射），因此覆盖整条冲刺路径——不用固定长度 AoE（否则激流冲出 5 格后就打不到）。伤害吃移速，取 `max(移速属性, 瞬时移速)`（沿袭全系列）；突进 `push` 的冲量会计入瞬时速度，故高移速/激流下爆发很高——这是激流流派的核心强度来源。
- **消耗融梦能量**：基础 1.0，**每级激流 +1.0（最多 4.0）**；`use()` 双端以基础 1.0 预检，`dash()` 双端按实际消耗校验、服务端扣费。
- **冷却**：基础 3s，**每级激流附魔延长 1s（最多 +3s，即 3~6s）**；接入战技**共享冷却**（`SkillCooldownHelper.applySharedCooldown`，随 `SKILL_COOLDOWN_RATE` 缩放，并联动其它 `#pasterdream:skill_cooldown` 武器）；投掷与突进共用矛的物品冷却（投掷冷却见 5.3）。
- **激流附魔**：增强冲量（档位 = 基础 2 + 激流等级，封顶 5，音效随档位切换），并**加成突进伤害**（每级 +25%）；代价是**每级 +1s 冷却、+1.0 能量消耗**（各最多 +3）。
- **横扫之刃**：每级 +0.5 格突进**溅射半径**（基础 1.5，封顶 +1.5）；**溅射最多命中 4 个实体**（主目标以外，按距主目标由近及远取，`DASH_SWEEP_MAX_TARGETS`，不限流派），且**伤害按距离线性衰减**（中心 100% → 边缘 40%，`DASH_SWEEP_MIN_RATIO`），避免高移速/高附魔下一发横扫清场。
- 与剑「疾风突进」**接受重叠，靠手感区分**（矛更长/更直/带雷）。

### 5.3 投掷（Shift + 右键蓄力）
- 蓄满掷出，消耗 1 耐久 + **1.0 融梦能量**。
- **虚影投掷**：投出的是**虚影**，**本体始终留在玩家手中**（`WindwreathedThunderSpearItem.throwSpear` 不再移除物品）。因此投掷后玩家死亡、或虚影落入虚空都不会丢失武器——这是本形态的核心防丢设计。
- 生成**新建独立弹射物实体**（**不复用** `ThrownTrident`：其构造函数硬编码 `EntityType.TRIDENT`、伤害写死 8.0F、渲染器写死原版三叉戟模型与贴图）。
- 投掷伤害吃移速。
- 命中目标或落地 → 触发连锁闪电 → **虚影自动飞回**；命中后 10s 内未命中也会兜底进入飞回（`WindThunderSpearEntity.tick`，`tickCount > THROW_COOLDOWN_TICKS`）。
- **冷却**：投掷后武器进入 **10s 冷却**（`THROW_COOLDOWN_TICKS`，复用 `player.getCooldowns()` 的物品冷却）；**虚影返回瞬间调用 `clearThrowCooldown` 立即解除冷却**。虚影丢失（投掷者死亡/离线）时冷却靠 10s 自然到期。
- **仆从防护**：弹射物穿过己方仆从/召唤物（`canHitEntity` 排除），不误伤；投掷击杀的掉落物同样被风卷（伤害源 `directEntity` = 雷矛弹射物）。
- **掉落物防护**：雷矛物品实体继承 `IndestructibleItemEntity`（免疫伤害、免疫虚空销毁，且 `Properties.fireResistant()`），与泰拉剑一致。

### 5.4 连锁闪电
- **仅投掷命中触发**，近战不触发。
- 从命中点跳跃到最近的其他敌人。
- **固定最大跳跃数 + 每跳伤害递减**（基础跳跃 4 次、每次 ×0.75，数值可调）。
- **引雷附魔**（原版仅 1 级，按「是否附魔」计）：附魔后，**引雷 + 锋利**共同提供**雷伤加成**（引雷 +20%、锋利每级 +10%），并增加**连锁次数**（引雷 +1、每 2 级锋利 +1）。
- 伤害吃移速。

### 5.5 被动
- **雷随疾风**：移速越高，近战/投掷/连锁雷电伤害越高（沿用剑的公式与命名）。
- **风卷掉落**：破坏方块或击杀生物时掉落物被吹到身边（复用 `FluffyWindAlloyToolHelper`）。

### 5.6 战技系统接入
- 加入 `#pasterdream:skill_cooldown` 标签 → 与其它战技武器**共享冷却**。
- 突进冷却走 `SkillCooldownHelper.applySharedCooldown`，随 `SKILL_COOLDOWN_RATE` 属性缩放。
- **共享增伤**（`SKILL_DAMAGE_RATE`）：投掷伤害、突进接触伤害均按 `getSkillDamageMultiplier` 放大；近战被动沿用剑的公式，不吃战技增伤。
- `SkillLockHelper.isSkillLocked` 在 `use()` 已接入（佩戴大侦探放大镜时锁定战技）。
- **融梦能量**：投掷固定 **1.0**；突进 = **1.0 + 每级激流 1.0**（最多 4.0）；`use()` 双端以基础 1.0 预检、`dash()` / `throwSpear()` 服务端按实际消耗扣费并同步（创造模式免费）。
- **仆从防护**：连锁闪电索敌、投掷弹射物、突进接触伤害均排除己方仆从/召唤物（`isOwnedMinion`）。

## 六、附魔与耐久

- 支持：耐久、经验修补、锋利、亡灵杀手、节肢杀手、火焰附加、**穿刺**、**引雷**、**激流**。
- **激流与引雷按原版规则互斥**（`TridentRiptideEnchantment.checkCompatibility` 排斥 `CHANNELING`/`LOYALTY`），同一把矛二选一：**激流=突进流**（增强冲量 + 每级 +25% 突进伤害），**引雷=投掷流**（命中召唤「萦风引雷」式效果雷：复用 `WindAlloyLightningEntity` 并 `setStrikes(1)`，**单道**纯视觉落雷 + 范围雷伤，**无天气/可见天空限制**；同时由**引雷 + 锋利**提供雷伤加成与连锁次数加成）。
- **禁用忠诚**（内置飞回已覆盖；且激流本身排斥忠诚）。
- 普通耐久，近战/投掷均耗 1。

## 九、残余风险

1. **无限飞行**：突进已加 3s 冷却，无限起飞风险大幅降低；剩余手感（冲量档位）留原型调。
2. **穿墙 / 免摔**：原版激流逻辑自带相关判定，风险低。
3. **雷电三来源**（近战附雷 / 投掷连锁 / 引雷）需明确主次，避免"什么都沾一点"。
